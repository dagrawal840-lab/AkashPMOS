# Reporting Guide

Last updated: 2026-03-20 · Owner: Miguel Torres (Data)

## Dashboards
The Reports page ships four default dashboards: Volume, First Response, CSAT, Agent Leaderboard.

## Getting data out
Click the **"Export CSV" button at the top right of the Reports page** to download the current view. For weekly board decks, export Monday morning after the ETL run finishes (~6am PT).

## Custom metrics
Ask in #data-requests. Turnaround is usually 2-3 days.
