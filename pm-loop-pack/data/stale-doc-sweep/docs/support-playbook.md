# Support Team Playbook

Last updated: 2026-07-01 · Owner: Dana Okafor (Support)

## Triage
All new tickets land in the Triage view. Use **Automations** (Settings > Automations) to auto-route by keyword and customer tier. (Note: this feature was called "Inbox Rules" before June 2026 — old screenshots in training decks may still show the old name.)

## SLAs
Priority tickets: first response under 1 hour. SLA breaches now fire a Slack alert to #support-alerts.

## Merging duplicates
Use bulk merge from list view (up to 20 tickets).

## Escalation ladder
L1 agent -> team lead -> Dana. Page on-call only for outages.
