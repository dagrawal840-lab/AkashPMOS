# Permanent Brain

Structured knowledge extracted from `inbox.md` during nightly consolidation.

## Structure

```
brain/
  ceo-plans/        → strategic direction, exec decisions
  office-hours/     → feedback, user signals, 1:1 notes
  eng-reviews/      → technical decisions, architecture notes
  people/           → contacts, relationships, context
  projects/         → per-project knowledge stubs
```

## Loading Discipline

- Load **headers only** by default (entity stubs)
- Load full document only when deep retrieval is required
- Every claim must carry its source: `[Source: inbox.md, 2026-06-06]`

## Conflict Log

Conflicts flagged during consolidation appear as:

```
### CONFLICT: [Original Concept] vs [New Context]
```

Review these in your daily digest before resolving.
